# Install: Conqueror SEO + AI Citations Brain

This is a hosted (remote) MCP server. Nothing to clone or build.

1. Add a remote MCP server named `conqueror-brain` with this URL (streamable HTTP):
   `https://brain.conquerorapp.com/mcp`
2. Config example:
   ```json
   {
     "mcpServers": {
       "conqueror-brain": {
         "url": "https://brain.conquerorapp.com/mcp"
       }
     }
   }
   ```
3. Sign in when the client opens the browser: enter an email address and the 6 digit code that arrives by email (OAuth 2.1, no API key).
4. Try: "Use the SEO + AI Citations Brain: what should I do this week to get my business recommended by ChatGPT?"
